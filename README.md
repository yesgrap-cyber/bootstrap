# Start Bootstrap - Página Freelancer

## Descripción

Este proyecto es una página web hecha con HTML, CSS y Bootstrap. Está basada en la plantilla "Freelancer" de Start Bootstrap. La hice para practicar lo visto en clase sobre Bootstrap y diseño responsive.

La página se adapta a celular, tablet y computador.

## Enlaces

 Sitio publicado: [https://yesgrap-cyber.github.io/bootstrap/]
 Repositorio: [https://github.com/yesgrap-cyber/bootstrap]

## Secciones de la página

 **Navbar:** menú fijo arriba con enlaces a cada sección. En celular se convierte en un botón de menú.
 **Inicio (Start Bootstrap):** avatar, título y descripción con fondo verde.
 **Portfolio:** galería de 6 imágenes organizadas en columnas.
 **About:** texto sobre el proyecto y botón de descarga.
 **Contact me:** formulario con nombre, correo, teléfono y mensaje. Todos los campos son obligatorios.
 **Footer:** ubicación, íconos de redes sociales y descripción.
